# Changelog

## 0.1.0 — initial public core

- Added normalized sales/advertising CSV reconciliation and aggregation.
- Added strict duplicate, value and missing-key validation.
- Added net-order and spend metrics with explicit zero-denominator handling.
- Added synthetic multi-marketplace examples, regression tests, CI configuration and bilingual documentation.
- Licensed the public reporting core under GNU AGPL-3.0-only.
