# Changelog

## Unreleased — development planning

- Clarified early prototype status and the distinction between experimental data collection and verified financial reporting.
- Documented the proposed official-report reconciliation, historical product costs, P&L, settlement controls and six-month development direction.
- Documentation changes only; no new financial calculations or live marketplace integrations are claimed.

## 0.2.0 — development milestone (2026-11-25)

- Added experimental read-only collection commands for Wildberries, Ozon and Yandex Market.
- Kept actual advertising expenses distinct from statistical spend; missing cancellation amounts are not inferred.
- Added local-only private output, explicit CSV mapping, mock API tests and bilingual setup guides.
- Native JSON-to-report normalization and live account validation are still pending.

## 0.1.0 — initial public core

- Added normalized sales/advertising CSV reconciliation and aggregation.
- Added strict duplicate, value and missing-key validation.
- Added net-order and spend metrics with explicit zero-denominator handling.
- Added synthetic multi-marketplace examples, regression tests, CI configuration and bilingual documentation.
- Licensed the public reporting core under GNU AGPL-3.0-only.

A version in this changelog identifies the source code, not necessarily a published GitHub Release.
