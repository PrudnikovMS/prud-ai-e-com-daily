# Contributing to PRUD AI e-com daily

Contributions from sellers, analysts and developers are welcome.

1. Open an issue describing the problem, marketplace, report type and expected behavior. For a new adapter, describe the exact export format and which metrics have comparable definitions.
2. Fork the repository and create a focused branch.
3. Add fictional fixtures only. Never include real account identifiers, credentials, personal information or private reports.
4. Add regression tests and document changed formulas or assumptions.
5. Run `python -m unittest discover -s tests -v` and the example command in README.
6. Submit a pull request describing why the change is needed and how it was verified.

Only submit material you have the right to distribute under the project's AGPL-3.0-only license. Keep discussion respectful and focused on evidence. Report security concerns privately as described in SECURITY.md.
